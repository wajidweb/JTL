# Journey Towards Life (JTL) - Web Portal

Website for **Journey Towards Life (JTL)** — Autism & Special Education Centre in Mingora, Swat, Khyber Pakhtunkhwa, Pakistan.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

## Build

```bash
npm run build
npm run start
```
